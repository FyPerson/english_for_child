## 1. 音频清单（冻结，共 56 条）

生成参数：edge-tts，`en-US`，候选音色 Jenny / Aria / Ana（先各出 3 词样品，家长和孩子试听定稿）；单词 `--rate -20%`，句子/词组 `--rate -10%`；输出 mp3 24kHz 48kbps 单声道；后处理只做**裁头尾静音 + 响度归一**（无降噪）。预算以最终 HTML 增量为准，目标 ≤ 1.2MB（56 条 × 约 12KB × base64 膨胀 1.33）。

构建自检（脚本强制）：① 清单每个键在 WORD_AUDIO 表中存在，缺失即报错；② 黑名单五词出现在清单或表中即报错；③ 页面所有 `data-say`/`data-phrase` 引用的键都在清单内。

| 组 | 类型 | 条目 | 数量 |
|---|---|---|---|
| A 练习词 | word | at, sat, it, in, sit, pat, pit, sip, tip, tap, an, nap, pan, pin, tin, nip, snap, spin | 18 |
| B 认读词 | word | I, a, see | 3 |
| C 第1天听音游戏 | word | sun, dog, sock, bag, cat, hat, cup, snake, milk, fish, map, book, bat, tree | 14 |
| D 音素示范词（补 A/C 未覆盖） | word | ant, apple, ten, top, igloo, pig, pen, nose, net | 9 |
| E 词卡墙补充 | word | Nat, naps | 2 |
| F 句子 | sentence | I see a pin. / Nat naps. / I pat Nat. | 3 |
| G 绘本页（去重后新增） | sentence | I see Nat. / Sit, Nat! / Nat sat. / Nap, Nat, nap! | 4 |
| H 词组（WALL_HINT） | phrase | at the door / an egg / in the box | 3 |

用途说明：C/D 组仅用于听音游戏与音素 demo 词条；E-H 组用于词卡墙（v2.6b 规则不变：at/in/an 先读单词再读词组）与绘本家长区；周检保留词无音频（D4）。

## 2. 播放层改造（Voice → WordAudio）

- 新增 `WORD_AUDIO = { key: dataURI }`；`WordAudio.play(key, opts)` 为唯一入口。
- **仲裁**：全局单播放器。任何新播放先停止在播的音素音、单词音、系统 TTS；切换页面/游戏时停止全部声音（挂在现有 `clearPageTimers()` 同一节点）。
- **失败可见**：`play()` 失败（缺键 / 解码失败 / 播放被拒）→ 页面顶部出中文提示条「声音没放出来，点这里再试一次」，点击重试。系统 TTS 仅作非承诺兜底（检测到英文语音才用），兜底也失败则显示提示条。
- **锁答题**：听辨类游戏（抓抓乐 / 两扇门 / 点单）播放期间禁用作答按钮，播完解锁；播放失败也解锁并显示重试。
- 移除 v2 Voice 模块的 kick/setTimeout 时序 hack，不保留两套时序逻辑。
- 首次播放由用户点击触发（浏览器手势策略），页面不自动出声。

## 4. 六游戏契约

### G1 声音抓抓乐（Day1，P0）

| 字段 | 规格 |
|---|---|
| 轮次 | 轮 A：/s/ 词首，蛇+气球主题，口令「开头听到 sss 就拍」；轮 B：/æ/ 词中，蚂蚁+苹果主题，口令「听到词的肚子里藏着 æ 就拍」。两轮视觉主题与口令截然不同 |
| 题库 | 轮 A：sun·dog·sock·bag·snake·milk·sit·fish（正例 4）；轮 B：cat·dog·hat·cup·map·book·bat·tree（正例 4）。固定白名单，无保留词 |
| 题数/顺序 | 每轮 8 题，随机顺序 |
| 操作 | 自动播词（可点喇叭重听一次）→ 3 秒作答窗内点/不点气球 |
| 反馈 | 对：气球爆开 + 词义小图；错拍：气球晃动不爆；漏拍：下一题前轻提示。无惩罚音效 |
| 通关 | 8 题对 6；不达标可整轮重来，无次数限制 |
| 记录 | `games.grab.{s,a}.best`（最好对题数） |
| 降级 | 工期不够时只上轮 A，轮 B 保留 v2 家长玩法（H-2 拍板） |

### G2 积木合体（blend 替换，P1）

| 字段 | 规格 |
|---|---|
| 题库 | 当天 blend words（数据驱动） |
| 操作 | 默认点选：依次点字母积木（点即发音素，复用内嵌音素音）→ 点「合体」→ 动画合成 + 插画蹦出 + 整词音频；鼠标拖拽合体为增强路径 |
| 通关（逐词） | 合成后出现家长确认条「孩子自己读出来了吗？」→ 长按 1 秒确认 → 该词 ✓；配「再听一次 / 再试一次 / 撤销」 |
| 记录 | 家长确认的词进战利品墙（`games.trophies`） |
| 完成 | 当天词表逐词过完即结束，不强制全确认 |

### G3 两扇门（pair 替换，P2）

| 字段 | 规格 |
|---|---|
| 题库 | 仅当天及之前已学字母组成的词对（Day3 = sat/sit）；每题从词对随机播一个 |
| 题数 | 10 题；通关 10 对 7 |
| 操作 | 播词（播放期锁答）→ 点两扇写词的门之一 |
| 反馈 | 对：开门 + 插画；错：门晃动 + 自动重播一次该词（该题计错，继续下一题） |
| 记录 | `games.doors.best` |
| 边界 | 未学字母词对永不进入本游戏（H-3 通则） |

### G4 点单游戏（Day7 听音摆积木替换，P2）

| 字段 | 规格 |
|---|---|
| 题库 | at, it, an, in, sat, pin, nap（两音起步→三音，无保留词） |
| 操作 | 播词 → 点积木架字母 → 点槽位放入（点已放积木撤回）→ 摆满自动校验拼写 |
| 反馈 | 拼对：积木亮 + 家长确认「他指读了吗」（长按）；拼错：积木抖动，可重摆，第 2 次错后给首字母提示 |
| 通关 | 无硬性通关，摆对 3 个即算完成打卡建议值 |

### G5 造词工坊（Day7 积木造词替换，P2）

| 字段 | 规格 |
|---|---|
| 素材 | 12 块积木（s a t i p n × 2），3 槽 / 4 槽自由切换 |
| 真词判定 | 白名单 = A 组 18 练习词。摆出白名单词 → 中性提示「拼出一个词！读读看」→ 家长长按确认读出 → 点亮战利品墙 |
| 假词与黑名单 | 反馈完全一致：「这个组合，读读看」（解码训练）。黑名单词绝不出现"这是真词"信号（C-1） |
| 时长 | 无通关；建议 12 分钟，超时 Nat 打哈欠软提示（不弹窗） |

### G6 计时闪卡（增强，P1）

| 字段 | 规格 |
|---|---|
| 逻辑 | v2 现有计时闪卡不变，加 `games.flash[组键].best` 历史最好成绩 |
| 反馈 | 破纪录：彩带 + Nat 庆祝；未破：只显示本次与最好成绩 |
| 边界 | 周检（exam）内不引入任何计时/纪录机制 |

## 5. 元游戏层

- **积木点亮墙**（P0）：首页 satipn 六块积木，按"该音所属天已完成"从 `dayDone()` **派生**点亮，不另存状态。
- **战利品墙**（P1）：词卡墙复用——家长确认读出的词正常显示，未确认的词灰色剪影。数据源 `games.trophies`。
- **Nat 庆祝**（P1）：复用 nat() SVG 姿态，step 完成 / 破纪录时播放；动画一律可点击跳过；exam 内禁用。
- **日卡盖章**：沿用 daycard--done，完成时加一次彩带。

## 6. 状态模式

```js
state.games = {
  grab:   { s:{best:0}, a:{best:0} },
  doors:  { best:0 },
  flash:  { /* 组键: best 秒/个数 */ },
  trophies: [],          // 家长确认读出的词
  confirmed: {}          // G2 逐词确认: { day2:['at','sat'] }
}
```

- KEY 不变（`soundblocks-w1-v1`）；读取时深合并默认值；`games` 解析失败→丢弃重建（不动 `days`）。
- 可派生的不存（积木点亮、日盖章均派生）。
- 进度连续性：孩子周一从 v3 零进度开始；上课期间所有更新**同名覆盖 week01-v3.html**（同 file:// origin，localStorage 天然保留）。v2→v3 改名只发生在开课前，无迁移需求。

## 9. 剩余风险与对策

- **edge-tts 依赖网络与工具可用性**：今天上午即跑通样品；失败降级链 = Windows SAPI 本机英文语音离线生成 → 家长自录 → D10 应急预案。
- **音色不满意**：样品先行，定稿后才批量。
- **工期挤压**：P2 全部可滑动，P0 不可滑动；范围再砍时先砍 Nat 庆祝与战利品墙，不砍音频与 G1。
