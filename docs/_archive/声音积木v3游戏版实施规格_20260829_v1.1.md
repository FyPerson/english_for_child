## 1. 音频清单（冻结，共 56 条）

**音色定稿：en-US-JennyNeural**（2026-08-29 三音色 × 3 词样品试听通过；更换音色只需改 manifest 一个字段重跑生成）。生成参数：edge-tts；单词 `--rate -20%`，句子/词组 `--rate -10%`；输出 mp3 24kHz 48kbps 单声道（edge-tts 默认输出即此规格，样品实测单词 10.6–12.4KB）；后处理只做**裁头尾静音 + 响度归一**。预算以最终 HTML 增量为准，目标 ≤ 1.2MB。

## 2. 播放层改造（Voice → WordAudio）

### 2.1 异步契约（H-3）

`WordAudio.play(key, opts)` 为唯一单词/句子播放入口，返回 **Promise，永不 reject**，resolve 为：

```js
{ status: 'ended' | 'failed' | 'cancelled' | 'blocked' }
```

- `ended`：完整播完。
- `failed`：缺键 / 解码失败 / play() 被拒 / **8 秒超时兜底**（防 ended 事件丢失挂死调用方）。触发失败提示条（§2.3）。
- `cancelled`：被更新的播放请求或切页打断。**不触发提示条**。
- `blocked`：黑名单守卫拦截（§2.5），console.warn，无任何 UI。
- **递增令牌**：模块内 `playSeq`，每次 play 自增。旧请求的回调凭令牌失效——旧 Promise 立即以 `cancelled` resolve，其后续 UI 操作一律不执行。
- `opts.rate`：playbackRate（慢速 0.8 复用同一 clip，不生成慢速版音频）。

### 2.2 仲裁

全局单播放器。任何新播放先停止在播的音素音、单词音、系统 TTS；切换页面/游戏时停止全部声音（挂在现有 `clearPageTimers()` 同一节点，week01-v2.html:1473）。首次播放由用户点击触发（浏览器手势策略），页面不自动出声；游戏内"自动播题"必须发生在"开始本轮"的用户手势之后（§4.1）。

### 2.3 失败可见

`failed` → 页面顶部中文提示条「声音没放出来，点这里再试一次」，点击重播同 key。系统 TTS 仅作非承诺兜底：检测到英文语音才尝试，兜底也失败仍显示提示条。兜底用 ≤10 行极简 `speakFallback(text)`，**不保留 v2 Voice 模块**（含 kick/setTimeout 时序 hack 与 `sayParts`——后者经 grep 确认全文无调用点，week01-v2.html:820 仅定义）。

### 2.5 黑名单守卫契约（C-1，统一五入口）

公共常量 `RESERVED = ['nit','sap','tan','pip','spit']` + 公共函数 `Guard.isReserved(word)`。五入口：

1. **真词判定**（G5）：白名单 = A 组 18 词（本身不含保留词），查询前再断言非保留词，双保险。
2. **音频**：`WordAudio.play()` 入口拦截保留词键 → `blocked`（§2.1）；build 断言清单/WORD_AUDIO 无保留词（§10 自检 ②）。
3. **目标生成**：G1/G3/G4 题库为静态白名单常量，build 断言不含保留词（§10 自检 ⑤）。
4. **示例渲染**：词卡 / 示范词 / 战利品墙渲染入口过滤保留词。exam 静态卡（§3.1）是唯一合法展示处——无音频、无点亮、无任何"真词"信号。
5. **战利品写入**：`confirmWord()` 入口拒绝保留词（§6.1）。

运行层守卫触发 = console.warn + 静默（不出提示条）；它是兜底，构建层校验保证正常路径永远到不了它。

### 3.1 周检隔离作用域（M-2 + D6）

**作用域 = exam 所在 step 的内部反馈全禁**：无单词音频（保留词卡片静态化，移除 v2 1434 行 `data-say`）、无逐题正误反馈、无提示、无纪录/计时、无战利品变化、无庆祝动画。

**保留的**：日级机制不属于隔离范围——Day7 的 checks 打卡、`dayDone(7)` 日卡盖章与彩带照常（"做了周检"本身值得盖章，被隔离的是周检**内容**的反馈）。

配套文案改写：v2「读完再点卡片核对」改为无音频版本；exam 家长折叠区补一句核对提示（家长可用第 1–6 天的音素按钮自己先拼一遍）——纯指导文本，不引入单词音频。

### 3.2 pair 分流通则（L-1）

**词对可进 G3 ⇔ 词对两词的全部字母 ⊆ 该天（含）之前 sound 区已教音素集**。按 DAYS 静态数据在构建页面时判定，不依赖运行时进度。第一周结果：Day3 的 sat/sit 进 G3；Day3 的 pat/pit 与 tap/tip 含未学字母 → 保留 v2 家长玩法的**静态块**：无音频按钮、无判定交互，标注"只听不读"（家长口播）。

## 6. 状态模式

### 6.1 schema（H-4/H-5 落定）

```js
state.games = {
  grab:  { s: {best: 0}, a: {best: 0} },   // count 大优
  doors: { best: 0 },                       // count 大优
  flash: { /* 组键: {metric:'elapsed'|'count', value:Number} */ },
  confirms: { /* 词: {g2:Bool, g4:Bool, g5:Bool} —— 按词×来源 */ }
}
```

- **trophies 派生不存储**：`derivedTrophies() = confirms 中任一来源为 true 且非保留词的词`。
- **确认/撤销幂等**：`confirmWord(w, src)` → 置 true（保留词直接拒绝，§2.5 入口 5）；`unconfirmWord(w, src)` → 置 false。重复调用无副作用；全来源 false 的词从战利品墙消失。
- KEY 不变（`soundblocks-w1-v1`）；`state.days` 沿用 v2 逻辑不动。

### 6.2 读取清洗（M-3，字段级）

| 字段 | 规则 |
|---|---|
| `games` 整体 | JSON 解析失败或非对象 → 整体重建默认（**不动 days**） |
| `grab.*.best` / `doors.best` | 非有限数字 → 置 0 |
| `flash` 每键 | 值非 `{metric ∈ 两枚举, value 有限数字}` → 删该键 |
| `confirms` 每词 | 值非对象 → 删；g2/g4/g5 之外的键删；非布尔置 false；**保留词条目删除**（清洗层守卫） |
| 通用 | 数组/对象整体替换不深合并（当前 schema 已无数组，原则保留给未来字段）；不做 schemaVersion |

进度连续性：孩子周一从 v3 零进度开始；上课期间所有更新**同名覆盖 week01-v3.html**（同 file:// origin，localStorage 天然保留）。

## 10. 构建管线契约：tools/build_audio.py（H-2）

**输入**：`tools/audio_manifest.json`（§1 单一权威数据源）、已生成的 mp3 目录、week01-v3.html。
**失败行为**：任一自检不过 → **非零退出且不写任何输出**；输出为原子替换（先写临时文件再覆盖）。

自检七项：

1. **唯一性断言（H-1 采纳部分）**：manifest 键去重后条数 == 条目数 == 56。
2. **黑名单断言**：RESERVED 五词不出现在 manifest 或 WORD_AUDIO。
3. **引用覆盖**：页面全部静态 `data-say`/`data-phrase` 字面值 + `BOOK.pages[].line`（规范化后） ⊆ manifest 键；反向：manifest 键 0 缺失 mp3。
4. **黑名单渲染检查**：RESERVED 五词不出现在任何 `data-say`/`data-phrase`（exam 静态卡无 data-say，天然通过）。
5. **题库断言**：G1 两轮答案键（正例+负例）、G3 词对、G4 词表 ⊆ manifest 键且不含 RESERVED；G5 白名单 == A 组 18 词。
6. **音频完整性**：每条 mp3 可解码、时长 > 0、裁静音+响度归一已执行。
7. **体积报告**：注入后 HTML 增量输出到 stdout，> 1.2MB 时警告（不阻断，人工判断）。

生成脚本（edge-tts 调用、断点续跑）与注入脚本可为同一文件的两个子命令；生成后**逐条人工听检**仍是必经步骤（§8 P0）。
