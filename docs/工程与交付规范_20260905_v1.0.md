# 工程与交付规范

后续工程入口补充：完整开发流程以 [长期维护指南](development.md) 为准。周清单在 `project.json`，媒体声明在 `frontend/src/media/`，统一命令为 `tools/project.py`，发布产物输出到 `dist/<内容版本>/`。下文的存储、教学与回归契约继续适用。

2026-09-07 起生成物不入库：产物在 `build/`，`python tools/project.py check` 含可重现构建与单文件基线比对，CI artifact 与 Release 是下载入口（工程健康化实施方案 v1.3 第 0 期）。

本规范更新旧周课件设计规范的工程部分。课程内容仍以六年课程方案为准。旧文档中的“无构建步骤”“复制上一周 HTML 后多处替换”和“G1/G2/G6 未覆盖”不再代表当前实现。

## 源码与构建

开发时使用公共引擎和周数据，交付时仍是单文件全内嵌，产物在 `build/`。`tools/build_lessons.py` 展开 `frontend/src/` 内的 include，先对全部目标执行数据契约与 JavaScript 语法校验，再原子替换各输出文件。`--check` 只比较，不写出。

`frontend/src/shared/` 共享状态、持久化、测评、六个游戏、内容块、长按与移动端补充样式。各周保留主题、首页、原有播放层和媒体模板。第一周保留每个字母两块的积木架，第二周保留原积木数量，第三、四周分组；这些差异由 `META` 声明，不复制游戏逻辑。

`frontend/src/weeks/weekNN.data.js` 是课程与题库的编辑入口。`META` 声明周次、存储键、积木架、点亮墙、是否巩固周、是否分组和快闪成绩上限。`tools/extract_data_layer.py` 只导出派生快照；`tests/fixtures/week02-data.js`、`week03-data.js` 为历史交接快照，不参与生产构建。

播放层沿用现有实现。重写它不是此次共享化的前提；其原有 generation/token、取消状态和物理停音保护必须保留。

## 进度可靠性

- 逐日清洗只保留本周有效打卡键的布尔值，异常单日数据不会让首页崩溃。
- 游戏历史纪录继续按既有范围清洗，未知确认词删除，无穷大计时值拒绝。
- 保存写入后读回验证；失败明确提示，保留内存进度，支持重试与导出；关闭页面前尽可能提示未保存。
- 读取失败不自动覆盖原存储。后续正常操作会尝试保存当前状态，提示中已说明原记录未读入。
- 备份格式为 `soundblocks-progress`、`schemaVersion:1`、`storageKey`、`exportedAt`、`state`。超过 1 MB、跨周、未知版本拒绝。
- 导入先预览，再由家长点击恢复；失败不切换当前内存进度。恢复前可导出当前状态。日期、打卡、游戏、测评共同备份。
- 备份用于恢复当前周，不等同于课程方案里程碑 4 的跨周年度摘要；没有账号或自动云同步。

## 第四周起的契约

`RESERVED` 与 `RESERVED_RETEST` 各五个已教 CVC 词。`PROBE_A`、`PROBE_B` 在段末周各五个，其余周为空。`GLOBAL_RESERVED` 在 W4—W40 必须完整包含附录 B 的四十词。

所有词池逐词规范化后检查重复和交叉冲突，不得出现在教学词典、游戏、闪卡、小书、说明或嵌套教学字段中。词义单独放 `ASSESSMENT_WORDS`，不借用教学词典 `W`。

W4 必须是巩固周：无首教新字位、点亮墙十九块，拼读、阅读、输出、打卡块齐全。`ASSESS_TEXT` 至少六十词，字位在已教范围内；非认读词不能进入教学词典，与所有测评词池互斥；全文和整句不得复用于教学。`TAUGHT_SIGHT` 是累计已教认读词，不能借它偷偷加入新认读词。

界面点击“开始”后才挂载测评词／短文；没有点读和配图。记录落在 `state.assessments`，刷新和备份均保留。阅读记录包括错误数、是否提示、能否说出主要事件。W4 两组总分单独显示基线建议。

## 检查入口

`./tools/check.ps1`（Windows）或 `python tools/run_checks.py` 完整运行：生成物一致性、数据／语法、契约反例、存储／备份、G1—G6、W4 测评、移动端、长按面板、旧 W2／W3 冒烟。缺依赖或检查失败会返回非零状态。

G1—G6 使用浏览器虚拟时钟和确定性音频桩，动作走 DOM 点击／键盘，不直接调用游戏结算函数。检查回合完成、精确成绩、落盘、刷新恢复，并覆盖失败重试、撤回、长按中断及快闪中途退出。音频桩验证的是状态机，不证明扬声器或发音质量。

移动端检查通过本地 HTTP，覆盖 320、390、768、1280 像素、逐天展开、可见图片、页面无横向溢出、触摸摆放与撤回、断网后页面内导航。`test-results/screenshots/reliability-mobile/` 保存截图。长按面板另外覆盖鼠标主键／右键、键盘、触摸滑动取消与存储删除失败。

## 触屏与上线

主要触屏按钮最小 44 像素，输入框至少 16 像素；窄屏家长面板换行、进度点适配、保留焦点圈、尊重减少动画设置。长按支持鼠标／键盘／触摸；移位、释放、取消、多点触摸、失焦或页面隐藏会取消，页面切换回收计时器。允许浏览器滚动与缩放，不全局禁止默认触摸行为。

当前根目录四个课件可直接放到 HTTPS 静态主机，URL 保持 `/week01.html` 等稳定路径。购买域名与选择托管服务可以稍后完成，不需要先改成框架应用。上传课件文件即可，不要把完整仓库、`tmp/` 或原始音源目录当成网站根目录上传。

建议域名从第一天固定使用 HTTPS 和一种主机名（例如统一带或不带 www）。`localStorage` 按来源隔离，本地文件、HTTP／HTTPS、不同域名和不同设备不会自动共享进度；迁移使用本周 JSON 导出／导入。[MDN：localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)

这里的离线能力是“已打开页面内的素材与导航可用”，不是承诺网站关闭后仍能离线重新打开；尚未添加 Service Worker 缓存。单文件下载后本地打开是另一条离线使用路径。

域名上线前还需真实 Android Chrome 与 iPhone/iPad Safari 验证：第一次点音、连续播放、切后台再返回、静音／锁屏、长按后滑动、文件下载与备份导入。桌面 Chromium 的触屏模拟不能代表这些真实设备行为。本轮没有购买域名、创建托管账户或发布公共网站。
