# 日期开放与重新开始

适用：第一至四周单周课件与合并入口。

- 未设置日期时可体验第一天；设置后按设备本地自然日每天开放一天，与本周打卡完成状态无关。未来开课日期在开课前不开放日课。
- 已开放的日课可复习；漏学后可返回未完成日，不自动跳转。页面保持打开时每 30 秒及回到页面时刷新开放状态。
- 修改开课日期默认保留本周记录；勾选“同时清空本周进度”时一并清空。修改日期会重算开放状态并取消暂停及提前开放设置。
- “本周从头再来”选择独立的新日期，长按确认后清空本周打卡、游戏成绩、测评结果，再按新日期开放。其他周和主题保留。请先导出备份。
- 家长可暂停日期推进，恢复时按暂停天数平移开课日期；也可提前开放下一天。
- 日期设置与重置先完整写入并读回核验，保存失败不在内存中清空原进度。
- 合并课程的跨周完成规则保留，周内日期开放与跨周规则独立。
- 日期来自设备，不是防篡改系统；备份包含开课、暂停和提前开放设置。

验证：新增 test_date_schedule.py 覆盖四周与合并入口的日期、打卡独立、保留/清空、暂停恢复、提前开放、备份与存储失败；原游戏和布局回归显式设置已开满七天的日期。
