# 第三周数据层交接（给外部模型）

**这份文档是给写第三周课程内容的模型看的。** 把它 + `tools/week-checks/week02-data.js` 一起交给对方即可，不需要给整个仓库。

---

## 0. 你要做什么，不用管什么

**你要做的**：写出第三周的**课程数据层**——一个 JS 文件，里面是音素教学数据、词库、七天课程、小书故事、四个游戏的题库、以及所有给孩子和家长看的文案。

**你不用管的**（都在仓库这边做）：

- HTML、CSS、任何渲染代码——引擎是现成的，跨周不动
- 周主题背景色——那是 CSS 层的事
- 音频生成、插画生成、base64 内嵌、打包
- 怎么把你的产出装配进课件

一句话：**你写内容，装配和验证在这边。**

---

## 1. 交付格式

**基于 `week02-data.js` 改一份 `week03-data.js` 交回来。** 不要从零写——照着改准得多，而且能保证结构对得上。

那份文件是自包含的：`META` + 12 个常量。它可以被校验器直接跑：

```bash
node tools/week-checks/check_data.js week03-data.js
```

所以你交回来之后，第一件事就是跑这个。它会逐条告诉你哪里不合格。

**重要：`SOUNDS` 和 `W` 是累计的，不是整体替换。** 第一、二周的音素记录和词条要**原样保留**（快闪复习要读旧音的 `ipa`/`mem`，G5 白名单和 G3 词对也会用到旧词），你只在后面追加第三周的。这是第二周踩过的坑，规范 §5.1 已写明。

## 2. 第三周的既定约束

| 项 | 值 | 说明 |
|---|---|---|
| 新音素 | `g o u l f b` | 合成拼读标准分组第三组，不要改顺序也不要换别的音 |
| 累计音素 | 19 个（`satipn` + `ckehrmd` + `goulfb`） | `SOUNDS` 的键必须正好是这 19 个 |
| 存储键 | `soundblocks-w3-v1` | `META.storageKey` |
| 点亮墙字母 | `goulfb` | `META.wallLetters`，只显示本周新音 |
| 七天节奏 | 前 6 天各 30 分钟，第 7 天 `rest:true` | 每天分钟数必须**加起来正好 30** |
| 认读词 | 新增 ≤ 3 个 | 累计第一周 `I / a / see`、第二周 `the / is` |
| 周检词 | 5 个，全 CVC，本周任何地方都没出现过 | 见 §4 铁律 3 |

**一个需要你给建议、但由人拍板的设计问题**：

G5 造词工坊的积木架，第一周 12 块、第二周 13 块，到第三周按老办法就是 **19 块**——对 7 岁孩子来说找字母会开始吃力。请你在交付时**附一段说明**，提出你的处理建议（按题库收窄？按元音/辅音分组？只放本周 + 高频旧字母？），不要自己默默决定。这条校验器查不出来，需要人判断。

## 3. 数据层 schema

### `META`

```js
const META = {
  week: 3,
  storageKey: 'soundblocks-w3-v1',
  rackG4: '...',          // G4 点单积木架字母，每字母 1 块
  rackG5: '...',          // G5 造词积木架字母，每字母 1 块
  wallLetters: 'goulfb',
  flashCapacity: { flash_words: N },   // N = 本周计时闪卡的实际条数
};
```

### 12 个常量

| 常量 | 形状 | 换周动作 |
|---|---|---|
| `RESERVED` | `['w1','w2','w3','w4','w5']` | 整体替换。5 个 CVC 周检词 |
| `SOUNDS` | `{键:{L,ipa,type,art,mem,cue,challenge,try,pass,how,warn,demo,audioKey?}}` | **累计**：保留 13 个旧音，追加 6 个新音 |
| `W` | `{词:{zh, art}}` | **累计**：保留仍被引用的旧词，加本周教学词 + G1 干扰词 + 保留词 |
| `WALL_HINT` | `{词:{en,zh,say}}` | 词卡墙上要连读词组的功能词；没有就留空对象 |
| `BOOK` | `{title, zh, pages:[{line,art,zh}]}` | 整体替换。6 页新小书 |
| `FIRST_TEACH_DAY` | `{字母:天数}` | 整体替换。只写本周 6 个新字母 |
| `G1_ROUNDS` | `{音:{pos:[4词], neg:[4词]}}` | 两轮，各 4 正 4 负 |
| `G1_THEME` | `{音:{title,icon,targetArt,cmd}}` | 键必须与 `G1_ROUNDS` 完全一致 |
| `G3_PAIRS` | `[['词a','词b'], ...]` | 最小对立词对，每对**只许差一个字母** |
| `G4_WORDS` | `['词', ...]` | 点单题库，每个词**不许有重复字母** |
| `G5_WHITELIST` | `['词', ...]` | 造词真词白名单，累计。不许含重复字母的词 |
| `DAYS` | 见下 | 七天课程主体 |

### `SOUNDS` 单条

```js
g:{L:'g', ipa:'/g/', type:'c', art:'<插画键>', mem:'一句话助记，带动作',
   cue:'动作口令，讲给孩子听，可嵌 <span class="en">g、g、g</span>',
   challenge:'实验名，四个字以内', try:'实验动作，家长带着做',
   pass:'成功标准，家长据此判断过没过',
   how:'发音原理（家长折叠区）', warn:'最容易错（家长折叠区）',
   demo:[['词','中文'],['词','中文'],['词','中文']]},
```

- `type`：`'c'` 辅音 / `'v'` 元音。第三周的 `o` `u` 是元音。
- `art`：插画键，用英文小写单词（如 `guitar`），后面会照这个键去生成图。
- **键必须是字母本身**——引擎按"字母即键"查 `SOUNDS[c]`。一音多形要建别名键并标 `audioKey`（第二周 `c`/`k` 的写法，照抄）。

### `DAYS` 结构与块类型

```js
{ n:1, wd:'第一天', title:'…', sounds:['g'], goal:'…', rest?:true,
  steps:[ { t:'步骤名', min:4, blocks:[ … ] } ] }
```

可用的块类型（**只能用这些，不能发明新的**）：

| `b` | 数据 | 用途 |
|---|---|---|
| `lead` | `{html}` | 引导正文 |
| `list` | `{items:[html]}` | 项目符号列表 |
| `note` | `{tone,html}` | 提示条。tone：`bulb` 洞察 / `warn` 易错 / `ok` 鼓励 / `star` 里程碑 |
| `sound` | `{s:'音素键'}` | 音素实验室（自动渲染 SOUNDS 那条的全部字段） |
| `blend` | `{words:[…]}` | 积木合体，逐词拼读 |
| `words` | `{items:[…]}` | 图文词卡。**只能用于"拼完核对"**，绝不能用于裸读 |
| `sight` | `{items:[[en,zh]]}` | 认读词 |
| `sentences` | `{items:[[en,zh]]}` | 句子卡 |
| `pair` | `{pairs:[[a,b]],note}` | 最小对立词听辨（10 题结算） |
| `flash` | `{items:[{k:'音'}\|{k:'w',v:'词'}], timed?, recKey?}` | 闪卡，**纯文字无图**。裸读/快闪一律用它 |
| `book` | `{}` | 小书阅读器 |
| `table` | `{head:[],rows:[[]]}` | 表格 |
| `checks` | `{items:[[标题,补充说明]]}` | 打卡清单，每天必须有 |
| `g1`/`g4`/`g5` | `{}` | 三个游戏的挂载点 |
| `exam` | `{}` | 周检，第 7 天必须有 |
| `wordforge` | `{mode:'family', families:[{tail, heads:[…]}]}` 或 `{mode:'swap', pairs:[[a,b]]}` | 换头造词探索块（第二周第 3、4 天已用，范例见 `week02-data.js`）。可反复点、无结算；词必须在 `W` 里且只含已教字位 |

文案里可以用 `<b>`、`<span class="en">英文</span>`、`<br>`。英文单词一律套 `class="en"`。

## 4. 硬约束

### 校验器会查的（写错会被打回）

1. **周检词一个都不许出现在别处**——包括 `lead`/`note`/`table`/`list` 正文、小书句子、音素卡的 `mem`/`cue`/`demo`、G5 白名单、词卡墙。
2. **所有词的字母必须在累计 19 个已教字母内**。例外只有两类：认读词（不按规则拼）、G1 干扰词（只听不读）。
3. **积木架必须摆得出题库里每个词**——G4 订单词、G5 白名单逐词校验。
4. **`G3_PAIRS` 每对只许差一个字母**，长度必须相同。
5. **`FIRST_TEACH_DAY` 要和 `DAYS[].sounds` 对得上**，点亮墙字母集要和它一致。
6. **每天分钟数加起来 = 30**（休息日除外），每天必须有 `checks` 块。
7. **认读词每周 ≤ 3 个**。
8. **周检 5 个词，全是 3 个字母**。
9. `G1_THEME` 的键必须与 `G1_ROUNDS` 完全一致，每轮正负例各 4 个。
10. `SOUNDS` 每条的教学字段必须齐（缺一个就报错）。

### 校验器查不出来、但同样是铁律的

1. **合成语音绝不读单个音素**——所以音素的教学全靠 `cue`/`try`/`pass` 这三段文字让家长做动作。写的时候要想着"家长照着这段话能不能做出来、能不能判断孩子过没过"。
2. **图片不得先于拼读出现**——裸读、闪读、计时挑战一律用 `flash`（纯文字）。用了 `words`（带图）就是把答案先给了孩子。校验器只能查步骤名带"裸读/闪读/快闪"的情况，其余靠你自觉。
3. **四音词按辅音群位置选教法**：词首辅音群（如 `flag`）→ 从后往前接，先拼核心再加头；词尾辅音群（如 `gulp`）→ 先拼前三个音再补尾音。两种方向相反，写反了会让孩子更卡。
4. **每周只有一本小书，第 6 天读完**，句子只能用累计已学音素 + 已学认读词组成。
5. 文案对象是**家长**，语气是"跟一个正在陪孩子的成年人说话"，不是对孩子说教，也不是教育家长。第二周的文案是基准，照那个调子写。

## 6. 常见会被打回的错（第二周实测）

| 错法 | 后果 |
|---|---|
| 周检词顺手写进了某个 `note` 的举例里 | 铁律 3 破功，孩子周检前就见过了 |
| 裸读步骤用了 `words` 块 | 图片先于拼读出现，测的是认图不是解码 |
| 某天分钟数加起来 29 或 31 | 校验器直接报错 |
| `G5_WHITELIST` 里混进含重复字母的词（如 `dad`） | 积木架每字母 1 块，摆不出来 |
| 四音词只给"从后往前接"一种教法 | 词尾辅音群用这个方法更卡 |
| `SOUNDS` 整体替换掉旧音 | 快闪复习、G3 词对、G5 白名单大面积报错 |
| 发明了新的块类型 | 引擎不认识，渲染成空白 |

## 7. 你交回来之后的流程

1. 跑 `node tools/week-checks/check_data.js week03-data.js` —— 不过就打回重写
2. **人过一遍教学法**——难度梯度、词表合理性、小书故事、文案口吻，这些校验器查不了
3. 装配进 `week03.html`（复制第二周换数据层，换周主题背景色）
4. 扩音频清单，跑 `gen_audio.py` + `build_audio.py`
5. 按 §2 的键写第三周的插画提示词，出图后跑 `embed_assets.py`
6. 浏览器冒烟 + codex 审 → 提交
