# iPad 点按音频与字母居中修复（2026-09-08）

本次覆盖第一至第四周及合并课程。

- 字母按钮清除原生内边距与外观，使用明确的水平/垂直居中，保留原有积木底边厚度。
- 音素播放的 seek 与 play 分开处理，避免媒体信息未就绪时 seek 异常阻止播放；播放拒绝或媒体错误显示“点这里再试一次”。新请求或切页后，旧错误不能重新弹出提示。
- 单词/句子复用播放器，减少 Safari 连播对新媒体元素的播放权限限制；每次恢复正确语速。权限拒绝直接返回失败，交给已有重试流程。
- 不修改教学数据、录音与图片。进度存储格式不变。

验证：`tests/browser/test_audio_touch.py` 覆盖四周的 seek 异常、拒绝后触控重试、过期回调、播放器复用、倍率恢复、取消与居中样式。默认 Chromium；加 `--webkit` 可运行 WebKit，需先安装对应测试浏览器。两种引擎专项已通过。此测试的音频异常通过模拟注入，不等于真实 iPad 人耳试听。

参考：[WebKit iOS 播放策略](https://webkit.org/blog/6784/new-video-policies-for-ios/)、[WebKit 关于按媒体元素授权及复用的说明](https://webkit.org/blog/7734/auto-play-policy-changes-for-macos/)。这些规则说明兼容性风险，并不证明用户设备的唯一故障原因。

真机验收：刷新课件后分别点击字母、单词并测试慢速后常速连播；快速重复点按及切后台返回后重试；横竖屏观察字母框。浏览器引擎自动化无法代替设备输出音量、音频路由和人耳试听验收。
