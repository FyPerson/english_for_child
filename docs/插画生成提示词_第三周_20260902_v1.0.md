## 0. 出图管线

```
GPT 生成 (1024×1024 透明底 PNG)
  → 按 art 键命名，存入 assets/week03/{phoneme|word-cards|book}/ 与 assets/week03/celebrate.png
  → python tools/embed_assets.py --target week03.html --assets assets/week03
     （这一步内含规格化：192px / 描边 #232B28 3px / 留白 8px / 去外光）
  → node tools/week-checks/check_data.js week03.html
     python tools/week-checks/smoke_w3_browser.py week03.html
```

**文件名必须等于 art 键**（表格里"文件"那一列就是），工具按名字自动配对；
下划线开头的文件（角色定妆图）会被跳过，不进课件。

图是**可以分批补**的：跑一次注入一次，工具幂等，补几张跑一次都行。
先用 `--dry-run` 看一眼覆盖情况和有没有孤儿图：

```bash
python tools/embed_assets.py --target week03.html --assets assets/week03 --dry-run
```

**规格由脚本兜底，你不用纠结尺寸和留白**：`embed_assets.py` 内部就会调用 `unify_card_outlines.py` 做 192px 缩放、补 3px 深色描边、留白与去外光，而且**幂等**（重跑不会把描边越叠越粗）。**不需要单独跑 `unify_card_outlines.py`**。GPT 那边只要保证三件事：画风对、透明底、主体完整不出血。

副机上的完整命令清单见 `docs/三方分工与交接规范_20260902_v1.1.md` §3.1，只碰 `assets/week03/`。

### 0.6 关系场景覆盖条款（本周新增，第四周起沿用）

§1 的通用前缀写着 `Single subject, centered, facing the viewer`。**下面这些图天然是"关系图"**——两个主体、或主体与物件的位置关系才是词义——对它们，前缀里这三句**按本条款覆盖**，其余约束（透明底、无背景景物、无地面线、无文字、平涂无渐变、缩到 112px 可辨认）一律不变：

- 允许一个**紧凑场景**里出现最多两个主体（角色 + 角色，或角色 + 物件），两者贴近、整体仍居中；
- 允许**侧视或四分之三视角**的动作；
- 仍然不要背景、不要地面线、不要环境道具。

适用清单：词卡 `lap`、`big`、`mud`、`fog`、`gap`、`hug`、`get`、`dig`、`fit`（`fog` 是"树 + 雾块"一主体一物件的紧凑图标）；小书全部六页；庆祝图。生成这些图时，把这段话连同前缀一起给模型：

```
Exception for this relational scene: up to two closely placed subjects are allowed,
side or three-quarter view is allowed, the pair stays centered as one compact group.
Everything else in the style prefix still applies: transparent background, no scenery,
no ground line, no text, flat fills, no gradients.
```

## 7. 常见翻车与对策

| 翻车 | 表现 | 对策 |
|---|---|---|
| **画面里出现文字** | 图上带了单词、字母、水印、公交车路牌 | 通用前缀已含 `no text, no letters`。仍然出现就在提示词末尾再加一句 `Absolutely no typography of any kind.` 并重生成 |
| **加了投影或外发光** | 缩到 112px 后主体边缘发糊 | 前缀已禁；重生成时强调 `completely flat, no shading beyond two tones` |
| **描边粗细不一** | 和前两周的图并排看着"软" | 注入器（`embed_assets.py`，内含 unify）已统一补 3px 描边；注入后仍显软，说明原图根本没画描边或描边是浅色，重生成并强调 `bold uniform dark outline` |
| **主体太小或出血** | 脚本裁切后留白不对 | 要求 `fully inside the frame with even margin`，别让主体贴边 |
| **六页小书里角色变样** | 狗时胖时瘦、Dan 换了衣服 | 必须传三张角色定妆图当参考图，且六页一次连续生成，不要隔天补 |
| **狗画得不够大** | 第 6 页 Dan 和狗一样高 | 提示词里已写 `clearly taller and larger than him`；仍不够就补一句 `the dog's head is above Dan's head` |
| **`doctor.png` 嘴画圆了** | 与本周 /ɑ/ 口令"嘴唇不收圆"矛盾 | 重生成，强调 `jaw dropped wide open, lips relaxed and flat, not rounded` |
| **配色偏冷或偏艳** | 和前两周不是一套 | 把前缀里那六个色值原样给模型，不要让它自由发挥 |
| **白底带浅灰渐变** | 去背后边缘有脏边 | 要求 `pure flat white #FFFFFF, absolutely no shadow` |
