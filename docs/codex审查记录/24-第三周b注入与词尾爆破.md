**建议：采纳，本轮一并扩到 49 个。** 同一失效模式、同一个参数；23 个 b/g 词的复测已证明 -60 在这条 TTS 管线上不引入噪声（头部直接是语音起点、尾部是释放衰减）。分两批只是让用户听两次。k 结尾 0 丢，不动。
