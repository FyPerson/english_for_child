## 第二层：4 件套

- **采纳建议**：10 条全部采纳，一个 fix commit 后复审。
- **推荐理由**：H-1 是门禁失效级别；其余都在同一模块，一次修完复审一次比拖到第 2 步再翻两遍便宜。
- **反向理由**：M-3 codex 建议上 AST 解析器，但决定 H 不加 package.json，Node 自带没有解析器；用逐行静态属性扫描替代，只接受"一行一个普通属性、值是字符串"，等价于 AST 在这个受限语法上的作用。M-5 在本仓库不会发生，加断言是把契约写显，不是修 bug。
- **第十人视角**：codex 说提前接入 `check` 会造成"教学代码提交先红、重取基线才绿"的两提交窗口，属实；里程碑 2 改共享引擎时必然遇到。CI 按 push 只跑分支头，本地两 commit 一起推不红；副机若单独推一个改模板的 commit 会红。这是纪律成本，值得，但要写进交接规范 v1.2（第 1 期）。
