## 第二层：4 件套（采纳理由 / 不采纳理由 / 第十人视角）

### H-1（high / contradiction）`SOUNDS.o` cue 与 how/warn

> codex：cue 要求"嘴巴张得大大的、圆圆的"，how/warn 要求"嘴唇不用圆、不能发成喔"。无录音阶段家长最可能照 cue 做，会直接教错。

**建议：采纳。** cue 是家长第一眼照做的那句；六个新音目前没有录音纠偏；圆唇正好把 /ɑ/ 教成 warn 自己反对的"喔"。改法：cue 改为"像给医生看喉咙那样，嘴巴上下张大、嘴唇放松不收圆，短短地发 o、o、o"。
**不采纳理由**：找不到。"圆圆的"若指口腔张成圆形而非圆唇，家长读不出这种区别。
**🔟 第十人（基础假设）**：how 里写明目标是美式 /ɑ/（不圆唇）；英式短 o 是 /ɒ/（圆唇）。规范 §6 与音素 README 都没写音包口音。六个新音的真人录音如果出自英式音包，"不圆唇"的口令会和录音打架。→ 改口令的同时，录新音前先确认口音，让口令与录音一致。

### H-2（high / missing-constraint）小书第 6 页 hugs

> codex：hugs 结尾 s 读 /z/，不在累计十九音内，又是未标注的四音词；Day6 提示临时教"s 读得像 /z/"，与"小书只用已教音素"冲突。建议改 "Dan can hug the big dog."。

**建议：采纳。** can、hug 都是已教 CVC，句意不变；同步删 `W.hugs` 词条和 Day6 note 里"hugs 结尾的 s 读得像 /z/"那句；插画键 danHug 不动。
**不采纳理由**："Dan hugs the big dog" 更像故事结尾，而且孩子读绘本迟早遇到 -s。但"没有一个字靠猜"是本项目铁律，不能为一句话开例外。
**🔟 第十人（时间维度）**：课程方案 §5.3 后缀 -s（/s/ /z/ /ɪz/）排在 W28。现在提前 25 周偷跑一个例外，孩子心里会留下"s 有时读 z"的模糊规则，到 W28 反而要重讲。支持采纳。

### H-3（high / contradiction）WORD_AUDIO 与自述
