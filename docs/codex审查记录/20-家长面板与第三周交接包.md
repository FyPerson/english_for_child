## 第一层：非技术总结

三件事里，插画提示词的键名和音频清单都对上了，没有会让 GPT 生错文件的硬伤。真正要先修的是四处：① 家长设置入口在**触屏上**防误触不够——手指从按钮上开始滑动时页面滚不动，手指停住满 1.5 秒照样会开面板，这是我加的一条 CSS 和长按原语没处理"滑动"共同造成的；② "本周从头再来"如果浏览器没让删存储，页面照样刷新，家长会以为清成功了其实没清；③ 提示词文档说 `dog.png`、`hug.png`"复用"另一张图，但没写"复制成这个文件名"，副机机械执行会少两张图；④ 风格前缀写死"单主体、正面"，和小书、`lap`、`big` 这类双角色场景冲突，副机拿不准该听谁的。其余是断言假绿、键盘可达、几张词卡的可辨认度和一句文案。

## 第二层：4 件套

### H-1（high）长按原语的触屏与鼠标键
**建议：采纳，改在原语上。** 这是 `bindLongPress` 自身的缺口，G2 / G4 / G5 的家长确认同样受益；`touch-action:none` 是我这轮加的，删掉。触摸不再 `preventDefault`：滚动手势由 touchmove 取消计时来兜，长按弹出的系统菜单用 `contextmenu` 拦。
**不采纳理由**：改共享原语会牵动三个游戏的确认按钮；可以只改入口。但入口和确认按钮的问题是同一个。
**🔟 第十人（基础假设）**：我原写"这套课件主要在平板上用，触屏才是主路径"——**用户拍板时纠正：课件跑在 Windows PC 浏览器上，不是平板**。判断依据错了、结论不变：鼠标右键按住会触发才是主路径上的真问题，触屏部分降为兜底（带触屏的笔记本仍受益），改法与代价一样。已把运行环境写进规范 §0 / §2 和项目记忆，以后 brief 的项目语境按 PC 写。

### H-2（high）删存储失败仍刷新
**建议：采纳。** 删后读回，`getItem(KEY) === null` 才 `reload()`；否则面板显示"未能清除，请重试"，不刷新。
**不采纳理由**：找不到。
**🔟 第十人（历史踩坑）**：`feedback_fix_is_also_change`——异步/不可靠操作要按回调 / 状态 / 物理三层设防，这里连一层都没设。

### H-3（high）复用图的落盘映射
**建议：采纳。** §4 的 `dog.png` 行改成"生成 `_char_dog.png` 后复制一份存为 `word-cards/dog.png`"，`hug.png` 同理；总量改写为"独立生成 48 张、落盘 50 个文件"；§8 加"两份复制件存在且与源图一致"。
**不采纳理由**：第二周文档同样写"复用"，GPT 当时做对了。但那次是用户在旁边逐步确认，这次要机械执行。
**🔟 第十人（心智成本）**：多写两行命令，副机少问一次。

### H-4（high）前缀与关系场景冲突
**建议：采纳。** 前缀一字不改（跨周一致性来源），另加一节"关系场景覆盖条款"：列出 `lap` `big` `mud` `gap` `hug` 与六页小书，声明这些图允许两个主体、允许侧视、覆盖前缀里的 `Single subject, centered, facing the viewer`，其余约束不变。`fog` 改为"边缘清晰的不透明奶油色雾块遮住物体下半部，禁止淡出和半透明"。
**不采纳理由**：第二周小书也是这么出的、没出事。但第二周的词卡没有关系图，本周有五张。
**🔟 第十人（时间维度）**：这条覆盖条款下周还要用（W4 巩固周词卡更多关系图），写成通用条款而不是逐张注。

### M-1（medium）重置长按的取消函数
**建议：采纳。** `openParentPanel` 保存 `cancel`，在 close / setdate / 再次打开时先调用；面板 DOM 被替换前计时一定被清。
**不采纳理由**：触发窗口要求"一只手按着重置、另一只手点收起"，现实里几乎不会发生。
**🔟 第十人（成本价值）**：三行代码，值。

### M-2（medium）键盘可达

**🔟 第十人（基础假设）**：键盘长按同样防误触（Tab 到按钮再按住 1.5 秒，孩子不会这么干）。
