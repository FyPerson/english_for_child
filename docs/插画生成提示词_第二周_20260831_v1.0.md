# 第二周插画生成提示词 v1.0

**用途**：拿去 GPT（gpt-image-1 / DALL·E）直接生成第二周课件所需插画。提示词已按第一周定稿的实际画风反推，照抄即可，不要自行"优化"风格描述。

**画风真相源**：`assets/word-cards/*.png`、`assets/phoneme-mnemonics/*.png`、`assets/wall-nat/*.png`（第一周已定稿的 34 张图）。生成结果与它们并排看不出是两批，才算过。

---

## 0. 出图管线

```
GPT 生成 (1024×1024 透明底 PNG)
  → 存入 assets/week02/{phoneme|word-cards|book}/
  → python tools/unify_card_outlines.py    # 统一成 192px / 描边 #232B28 3px / 留白 8px / 去外光
  → 内嵌进 week02.html
```

**规格由脚本兜底，你不用纠结尺寸和留白**。GPT 那边只要保证三件事：画风对、透明底、主体完整不出血。

## 1. 通用风格前缀（每次生成都要带上）

> 复制这一段放在每个提示词前面。这是整套图的一致性来源，**一个字都不要改**。

```
Flat vector children's sticker illustration, storybook style for a 7-year-old.
Bold uniform dark outline in #232B28, consistent stroke weight, fully closed contours.
Flat fills with at most two-tone shading. No gradients, no glossy highlights,
no drop shadows, no outer glow, no cream halo.
Warm muted palette: cream #F0DFB8, tan #D9A441, coral red #D8492F, teal #1C6675,
sage green #48874E, soft brown #8B6239.
Rounded friendly shapes, simple confident forms, slightly chunky proportions.
Single subject, centered, facing the viewer, fully inside the frame with even margin.
Transparent background. Square 1:1.
Must stay clearly readable when scaled down to 112 pixels.
No text, no letters, no numbers, no watermark, no border, no frame,
no background scenery, no ground line.
```

**中文对照要点**：扁平矢量儿童贴纸风 · 统一深色描边 · 平涂最多两级明暗 · 无渐变无高光无阴影无外发光 · 暖哑光配色 · 圆润敦实造型 · 单主体居中正面 · 透明底 · 正方形 · 缩到 112px 仍可辨认 · **画面里绝对不能出现任何文字字母数字**。

### 如果模型不支持透明底

把最后的 `Transparent background` 换成：

```
Pure flat white #FFFFFF background, absolutely no shadow and no gradient on the background.
```

然后先去背再跑 `unify_card_outlines.py`。

## 7. 常见翻车与对策

| 翻车 | 表现 | 对策 |
|---|---|---|
| **画面里出现文字** | 图上带了单词、字母、水印 | 通用前缀已含 `no text, no letters`。仍然出现就在提示词末尾再加一句 `Absolutely no typography of any kind.` 并重生成 |
| **加了投影或外发光** | 缩到 112px 后主体边缘发糊 | 前缀已禁；重生成时强调 `completely flat, no shading beyond two tones` |
| **描边粗细不一** | 和第一周的图并排看着"软" | 跑 `unify_card_outlines.py` 会补一道 3px 统一描边，可救 |
| **主体太小或出血** | 脚本裁切后留白不对 | 要求 `fully inside the frame with even margin`，别让主体贴边 |
| **六页小书里角色变样** | 猫时胖时瘦、Dan 换了衣服 | 必须传角色定妆图当参考图，且六页一次连续生成，不要隔天补 |
| **配色偏冷或偏艳** | 和第一周不是一套 | 把前缀里那六个色值原样给模型，不要让它自由发挥 |
| **白底带浅灰渐变** | 去背后边缘有脏边 | 要求 `pure flat white #FFFFFF, absolutely no shadow` |
