# 周课件生产线

当前流程：修改 `frontend/src/` → `python tools/project.py build` → `python tools/project.py check` → 实际听检／试课 → `python tools/project.py release`。交付 `dist/<内容版本>/` 内文件。周清单与合并范围见 `project.json`，完整操作见 [长期维护指南](../development.md)。

公共状态、六个游戏、内容块、长按和移动端样式在 `frontend/src/shared/`。主题与课程数据分周维护；教学语义色不变。源码可以分文件，交付仍必须全内嵌。

旧 `port.py`、`port_w3.py` 是历史移植记录，不能用于第四周或覆盖新的公共引擎。旧数据快照不参与构建。素材工具更新根目录 HTML 后，用 `node tools/capture_lesson_media.js weekNN.html` 把媒体同步回 `frontend/src/media/weekNN/`，再构建。

详细参数、检查边界和上线方式见 [工程与交付规范](../工程与交付规范_20260905_v1.0.md)。

- W4 已完成无新字位巩固模板和预置测评契约；词卡墙 34 词全部有图。
- W5 必须先完成双字母积木里程碑。
- 新一周的主题色用 `python tools/theme_palette.py --week N --hue H --name 名 --apply` 生成并写入模板（色相避开前四周的 165 / 300 / 235 / 45；工具自带亮度、对比度与色域校验），然后 `python tools/baseline.py --create --force` 重取基线并单独提交。
- 第四周的插画只在 `frontend/src/media/week04/*.js` 里有源，`resources/assets/week04/` 只放五张补图原图：不要对第四周运行 `embed_assets.py` 全量重建。工程健康化第 1 期（09-14 起）把插画导出到 `resources/adopted/` 后按新管线处理。
- 素材继续遵守 [清单复用键整条继承](清单复用键整条继承.md)，发音验收继续由真人试听。
