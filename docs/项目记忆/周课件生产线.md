## 换周的固定模式

复制上周定稿 → **只换数据层** → 装配 → 音频 → 插画 → 审。
引擎、设计系统、播放层、六个游戏、状态 schema、打印、无障碍**跨周不动**。
第二周 77 项锚点替换全部断言唯一命中，一次成功。

**两个反直觉但必须守住的点**：

- `SOUNDS` 和 `W` 是**累计**，不是整体替换。旧音的记录要留（快闪复习读它们的 `ipa`/`mem`，
  G3 词对和 G5 白名单也用旧词）。第一版规范写成"整体替换"，被 codex 抓出来。
- **周主题背景色每周换是刻意设计**（用户明确），不是断裂。但元音红 / 辅音青 / 琥珀 accent /
  完成绿四个**教学语义色跨周冻结**——元音红是孩子要自己发现的规律，属教学内容不是装饰。
  安全色相区：紫 / 蓝 / 靛 / 灰绿 / 赭。

## 五个工具的分工

| 工具 | 干什么 |
|---|---|
| `tools/week-checks/check_data.js` | 数据层 360 项，**与周次无关**——已教字母集 / 词卡墙词数 / 认读词全部由数据推导，第三周原样可用。吃两种输入：周课件 HTML 或独立数据层 JS，结果一致 |

## 第三周怎么开工

音素 `g o u l f b`，累计 19。如果把数据层交给外部模型写，**要知道边界**：

- **GPT 的 Code Interpreter 跑不了 `tools/week-checks/check_data.js`**（Python 沙箱，没有 node），所以流程必然是
  "它写 → 拿回来 → 这边校验 → 打回"，一次往返省不掉。别指望它交出来的东西经过任何机器校验。
- **交接只给两个文件（约 45 KB），不要复制整个仓库**。给了完整 HTML 它大概率会直接去改 HTML
  ——那是明令禁止的，它没法跑语法检查。
- **机器能查"写错了"，查不了"写得好不好"**。难度梯度、词表合理性、小书故事、文案口吻
  必须人过一轮，不能校验绿了就直接装配。
- **待决设计题**：G5 造词积木架第一周 12 块、第二周 13 块，第三周按老办法是 **19 块**，
  7 岁孩子开始难找。交接文档已要求提建议、由人拍板，不许模型默默决定。

> **让外部模型写数据层之所以可行，不是因为它写得准，而是因为写错能被机器当场检出来。**
> 护栏（`tools/week-checks/check_data.js` 能吃独立数据文件）比交接文档重要——没有护栏，文档写得再好也只是许愿。
