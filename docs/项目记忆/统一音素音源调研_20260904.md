# 统一音素音源调研

## 结论

截至 2026-09-04，**没有找到一套可以直接替换本项目、同时满足全部条件的公开现成音源**：

1. 覆盖本项目 §5.1 的 42 个音（43 块基础积木）；
2. 同一发音人、同一口音、同一录音与后期体系；
3. 面向自然拼读的纯音，尤其 `/p b t d k g/` 不带 schwa；
4. 明确允许剪辑、内嵌到单文件 HTML，并随 GitHub 仓库再分发；
5. 音质足以长期充当孩子的统一模仿基准。

因此本轮**不整套替换**。第三周 `/b/` 作为已影响当前教学的单点例外，2026-09-04 从 TESSA A1 的六次独立
示范中选取第六次，经用户试听确认后替换原临时占位；其余已发布音素不作零散替换。等一套真正统一的母带准备好后，
再一次性替换并全量听检。

## 推荐路线

### 首选：一次性录制自己的 42 音母带

找一位稳定的 General American 发音人（优先有幼儿自然拼读或语音教学经验），在同一房间、同一支麦克风、
同一距离和增益下一次录完。每个音录 3–5 次；另外为塞音录 `p-p-p / b-b-b / t-t-t / d-d-d / k-k-k / g-g-g`
的连续示范，避免为了“拉长”单次塞音而变成 `puh/buh`。

录制前必须书面确认：项目拥有永久的剪辑、内嵌、公开仓库再分发和后续课程复用权。
建议母带规格为 WAV、48 kHz、24-bit、mono；保留未经降噪和未经裁切的原始母带，再由构建脚本派生页面 MP3。

这条路线成本高于继续找零散免费文件，但能一次解决口音、音色、响度、塞音做法和授权五个问题；
对于要连续使用六年的儿童课程，长期返工成本最低。

### 次选：先询问 Phonicademy 定制授权与补录

它的声音设计最接近本项目要的幼儿纯音。如果对方愿意提供：

- 允许内嵌与 GitHub 再分发的书面授权；
- 同一位 US 发音人补录本项目缺少的 `/ð/`、`/ʊ/`、`/ɚ/`、`/ɔr/` 等映射；
- 原始 WAV 或无损文件；

则可以进入候选听检。缺少其中任一项，都不能作为整套替换源。

## 替换门禁

整套新音源到位后不要逐周零散上线，按下面顺序一次完成：

1. 建立 42 音稳定键、IPA、书写积木、原始母带文件、授权证明的 manifest；
2. 机器检查格式、峰值、底噪、首尾裁切和键覆盖；
3. 成人逐个听检纯音，重点检查六个塞音、两个 `th`、两个 `oo` 和美音 r 控元音；
4. 先生成独立试听页，让用户逐个拍板；
5. 同一次变更重建所有已经发布的周课件，跑数据校验、浏览器冒烟与跨周复用检查；
6. 更新页面署名/许可说明，再提交仓库。
